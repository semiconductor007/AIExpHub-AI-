## 展示顺序

1. 进入实验管理，选择中文演示项目和批次一，查看参数、备注和已录入结果。
2. 比较批次一的三个实验，以“演示-基线实验-01”为基准，展示参数调整、最佳指标、差值、表格及图表。
3. 加入批次二实验，展示同项目跨批次比较与质量 / 速度 / 体积权衡：增强版质量最高，轻量版延迟最低、吞吐量最高、体积最小。
4. 仅选择“演示-适中学习率-02”和“演示-随机种子验证-04”，展示 Accuracy / F1 并列最佳；这些人工数值不能用于证明重复实验稳定或统计显著。
5. 可导出 CSV / PNG；需要 AI 总结时先确认发送预览，并建议勾选 /synthetic 与所需评测条件。录入和验证期间没有调用付费模型。
