# JSON 文件录入、批量导入与项目模板

2026-10-13 经用户授权实现。用于接收评测脚本已经计算好的结果，减少复制和逐条录入；不执行模型训练或自动计算评价指标。

## 页面使用

### 单个实验结果

在实验管理选中实验，打开“录入结果”或“编辑结果”，选择 UTF-8 `.json` 文件。文件使用平铺指标对象，例如先在项目中定义 latency_ms，再导入：

```json
{"accuracy": 0.91, "latency_ms": 7.5}
```

文件只填入表单，不自动保存。可以继续手动修改，点击“保存结果”采用最终表单值；未提供或为 null 的指标清空。非法文件不覆盖原输入，提示可关闭后继续手动录入，也可换文件重试。原有 JSON 粘贴与手动录入入口保留。

### 批量实验

1. 项目管理选中项目，在“共享评价指标”中点击“下载项目 JSON 模板”。也可在实验管理的导入弹窗下载当前项目模板。
2. 用真实编号、模型、参数及评测结果替换示例，或让评测脚本输出同样结构。
3. 实验管理选择目标项目与批次，点击“批量导入 JSON”，选择 / 拖入文件，或直接粘贴 JSON 草稿。
4. 点击“校验并预览”，核对规范化编号、模型、参数、结果及错误。可点击每行“修正”修改该条 JSON，或直接编辑整个草稿；修改后必须重新预览。
5. 所有行通过后点击“确认导入”。成功时实验列表自动刷新；确认前不会新增实验或结果。

每次导入只新增到当前批次，不创建项目或批次、不移动实验、不覆盖已有记录。前端文件与草稿限制为 1 MiB，前后端均限制 1～100 条实验；更大批次请拆分。只接收 JSON，不支持 CSV、压缩包或扫描整个目录。

## 文件格式

最小批量对象：

```json
{
  "experiments": [
    {
      "experiment_no": "EXP-NEW-001",
      "model_name": "ResNet18",
      "parameters": {"seed": 42, "batch_size": 32},
      "notes": "可选备注",
      "result": {"accuracy": 0.91, "loss": 0.2}
    },
    {
      "experiment_no": "EXP-NEW-002",
      "model_name": "ResNet18",
      "parameters": {"seed": 43},
      "result": null
    }
  ]
}
```

前端也接受上述 experiments 内的记录数组，并包装为请求对象。每条 experiment_no、model_name、非空对象 parameters 必填；notes 可选。result 为 null 或省略时创建无结果实验；提供 result 对象时，系统与项目自定义指标至少一项为有效数值。result 是平铺指标对象，不使用嵌套 custom_metrics；这里与现有单个 Result HTTP 请求结构不同。

项目模板包含 format_version=1、project_id、metric_definitions 和 experiments。metric_definitions 记录各项 key、name、unit、direction、lower_bound、upper_bound，仅用于说明与核对，不自动创建或修改指标。模板中的 result 全空值是占位：填写至少一项真实数值，或将 result 改为 null 后导入无结果实验。参数示例 seed=42 可自由替换，不要求固定参数键。

携带 project_id 时必须与目标批次所属项目相同。携带指标定义时，键必须存在，单位、方向和上下限必须与当前配置一致；显示名称变化不改变数值含义。模板过期时重新下载并核对，不能借用其他项目指标。未携带元数据的最小对象仍按当前项目规则校验每项结果。

## 校验和保存

- 编号 trim + uppercase；文件内部重复和系统全局重复均标明错误，不覆盖旧记录。
- 复用现有实验与结果 Schema：模型 / 编号非空、参数非空对象、有限数值、系统范围、自定义指标归属和范围、空结果规则；0 保留，null 不补默认值。导入还拒绝参数中的非有限数值。
- 未知字段或未知指标拒绝，不静默忽略。UTF-8 BOM 和大写 `.JSON` 扩展可读取；1e400 等溢出数值在客户端发送前拒绝，避免 JSON 序列化为 null。
- 预览只读，不创建记录、不提交事务；它不是锁定承诺。确认时重新校验编号和指标定义，再在一个事务内创建全部实验及可选结果。
- 任一行错误返回 422；数据库唯一性 / 外键 / 指标约束冲突返回 409 并回滚整批。成功返回 201，重复提交因编号冲突被拒绝。失败后重新预览再确认。
- 本轮没有改 ORM、数据库结构、依赖或原有结果更新语义。比较与图表继续读取最新有效结果。

## 新增 API

| 方法 / 路径 | 用途 | 语义 |
| --- | --- | --- |
| GET `/projects/{project_id}/import-template` | 下载项目格式示例和指标口径 | 200；项目不存在 404 |
| POST `/batches/{batch_id}/imports/preview` | 校验批量 JSON 对象 | 200 返回 can_import、total、valid_count、逐行编号 / normalized / errors；批次不存在 404，文档格式或项目 / 定义不符 422 |
| POST `/batches/{batch_id}/imports` | 重新校验并原子新增 | 201 返回实验列表；404 / 422 / 409，失败整批不保存 |

请求为 JSON 文档，不是 multipart 文件上传；文件在浏览器本地读取后发送结构化 JSON。预览 normalized 为有效记录的展示值；确认发送当前已预览草稿，服务端再次规范化与校验。没有预览 token、导入历史、自动覆盖或更新现有实验模式。
