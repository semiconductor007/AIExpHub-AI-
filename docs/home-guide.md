# 首页介绍与首次使用引导

2026-10-27：完善首页的信息和快捷入口，帮助首次使用者理解实验结构并找到录入位置。

## 首页内容

- 顶部介绍平台用途：记录模型配置和评测结果，比较实验并进行可视化分析。训练与指标计算在外部完成。
- 提供“新建实验”“创建项目”“比较实验”入口。
- 通过带图标、连线和示例的三张卡片解释 Project → ExperimentBatch → Experiment。项目共享指标、批次组织实验、单次实验保存具体配置及最多一份当前结果。结果可以稍后录入。
- 示例明确标注为非真实实验数据。一个项目允许多个模型；只有一组实验时可使用一个批次；比较允许跨批次、跨项目。
- 三张功能导航卡片分别介绍项目管理、项目工作区、实验比较的实际功能，明确实验和结果在工作区维护。
- 首次使用采用六步可点击卡片：创建项目、建立批次、录入实验、保存结果、勾选比较、查看分析。详细操作按需展开。
- AI 说明保留同项目、有效结果和共同指标等使用条件；点击首页入口不触发 AI 调用。
- 服务状态收在页尾，首次加载检查一次，保留手动重新检测，不持续轮询。

## 快捷操作与前置条件

1. 首页“新建实验”按需获取项目列表，选择项目后进入工作区并打开现有实验表单；所属批次仍需明确选择。
2. 没有项目时，提供“创建项目并继续”。保存项目后继续检查批次前置条件。
3. 项目没有批次时，打开现有批次创建表单。用户明确保存后，刷新列表并进入实验表单，带入刚创建的批次。
4. “创建项目”直接打开项目创建表单。普通创建完成后留在项目管理；从新建实验引导进入时继续原任务。
5. 步骤“建立批次”选择项目后直接打开批次管理；“保存结果”“勾选比较”选择项目后进入工作区，具体操作见展开说明。
6. 取消不会创建下一层资源。用户已经明确保存的项目或批次会保留，取消后不回滚这些记录。
7. 数据加载失败时显示错误并允许重试，不把加载失败视为无项目或无批次。

快捷入口仅使用 `action=create`、`action=new-experiment`、`action=manage-batches` 及可选 `next` 传递一次性操作意图。在打开对应表单前从地址移除意图；取消或刷新后不会反复弹出。工作区继续保留项目 / 批次上下文。
