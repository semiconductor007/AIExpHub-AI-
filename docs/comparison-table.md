# 指标对照表的展示方式

2026-10-27：将比较页原“一个实验一行、一个指标一列”的宽表改为指标纵向、实验横向的对照表。

## 展示与操作

- 表格采用细边框、浅色表头、清晰留白和对齐数值。列头显示实验编号与模型；项目、批次和结果状态可在“实验信息”中展开查看。
- 指标名称旁展示优劣方向，单位与项目归属跟随指标行。跨项目同名指标分别展示，不合并单位或数据。
- 最佳单元格使用绿色背景、加粗及星号；并列最佳全部标记。最佳始终来自后端对全部已选实验的比较结果，不根据当前显示分组重新计算。
- 选择基准后，基准列排在指标列之后，并在每一组中保留。其他实验的差值显示在原始数值下方，包含改善、退步、无变化或无法比较。
- 缺失指标显示“—”，未录入结果同时在列头标注，其他项目的自定义指标显示“不适用”。不使用 0 填充缺失值。
- 数值保留接口已取得的原始精度，较长数值允许换行并保留完整悬停文本；差值继续使用原有带符号格式。

## 多指标与多实验

- 支持按指标名称、键、单位或项目名搜索，以及选择显示哪些指标。
- 默认折叠全部已选实验均无数值的指标，显示数量并提供展开；“恢复全部指标”同时清除搜索、恢复选择并展开空指标。
- 新出现的指标默认选中，已删除指标从筛选状态清理。同一指标在刷新中保留勾选状态，切换分析标签保留搜索、选择及分组。
- 根据表格容器宽度，每组展示 1～4 个实验；存在基准时至少保留基准和一个待比较实验。列数超出时使用上一组 / 下一组，显示当前范围、总数及组数。
- 表格使用固定布局和可换行内容，指标增加只延长纵向内容；窄屏相应减少同时展示的实验列。
- 分组和筛选只影响表格展示。“导出完整比较 CSV”继续导出全部已选实验和全部指标，包括最佳标记及可选基准差值，不受当前显示分组和筛选影响。导出前仍获取最新数据。

## 验证

- 前端 70 项测试通过。新增 6 项覆盖原始精度、合法 0、空值和无结果、并列最佳、跨项目同键指标与单位、基准差值、筛选不改变源数据或 CSV、基准固定与完整分组、离屏最佳不被当前组替代，以及窄屏容量。
- TypeScript / Vite build 通过，保留原有大 chunk 提示。
- 独立临时 SQLite 库使用 8 个实验、21 项指标检查：默认折叠 4 项无数据指标、搜索、手动勾选、空选择、恢复、三组切换、基准固定、跨项目不适用、同名指标的 ms / s 分离及实验信息展开。
- 在最后一组仅搜索 latency 时下载 CSV，文件仍包含全部 8 个实验和 21 项指标，包含未显示的实验、空指标及基准差值。
- 实际浏览器检查 390px 宽度：指标列、基准列和一个待比较实验同时可见，使用分组切换其余实验。
- 现有演示项目进行只读页面检查，图表标签正常绘制，返回表格保留搜索状态。在另一标签页修改独立验收实验 Accuracy 为 0.99 后，表格自动更新，并保留原来的搜索和分组；无手动重新比较。

本次不改变 API、数据库、指标合法性、排名、图表或 AI 调用规则；现有本地业务数据按表比对保持一致，验收未调用 AI。
