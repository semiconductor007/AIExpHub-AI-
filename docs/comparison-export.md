# 比较结果导出

2026-10-27 完成经用户审核的比较表 CSV 与单图 PNG 导出，仅修改前端。复用现有比较 API、指标规则和 ECharts，没有新增依赖、接口或数据库结构。

## 使用步骤

1. 在“实验比较”中选择至少两个实验，按需要选择基准，点击“开始比较”。
2. 点击结果区域右上角“导出比较表 CSV”，下载当前实验集合的比较表。
3. 点击综合指标图、Loss 图或某个项目自定义指标图旁的“导出 PNG”，下载单张图片。没有有效数据的图不提供可用的导出按钮。

文件保存在浏览器的下载位置。文件名带 UTC 时间戳，例如 `AIExpHub_comparison_20261027T023213Z.csv`、`AIExpHub_project-3_latency_20261027T023358Z.png`；同名下载由浏览器按自身规则处理。

## 数据刷新与一致性

- 每次导出先调用一次现有 `POST /experiments/compare`，使用当前已选实验与基准重新比较。刷新成功后同一响应更新页面并生成导出快照。
- CSV 的指标、最佳及并列结果、基准差值来自该响应；不另行计算排名或把缺失值补成 0。
- 导出时锁定添加、移除、清空及基准切换操作；重复导出按钮也暂时禁用。自动同步收到的通知保留到导出完成后处理，不在生成图片过程中替换快照。
- 删除通知或离开页面使本次导出失效；异步生成图片后再次核对版本，失效时不下载。
- 刷新失败时不导出上次旧结果。普通网络失败仍按原有规则保留页面旧表图并明确标为未更新；实验不存在则清除旧比较并提示修正选择。
- 自定义指标在刷新后已删除、或者该图最新数据全部缺失时，不生成空白图片，给出提示。
- “数据获取时间”是浏览器取得本次比较响应的时间，不是训练时间或 Result 的修改时间。“导出时间”是本次文件生成任务建立快照的时间，均使用带 `Z` 的 UTC 格式。
- 项目和批次名称沿用当前比较页已选项的名称快照，同时保留响应中的项目 / 批次 ID；不把名称作为唯一标识。实验编号与模型名称使用刚刷新响应中的值。

并发保存可能在快照获取之后发生，文件表示所标注获取时间的一份比较快照；后续保存由原有同步继续刷新页面。平时不增加轮询或定时检查。

## CSV 内容与格式

每个实验一行，顺序与比较响应 / 页面一致。固定信息包含实验 ID、编号、模型、项目 ID / 名称、批次 ID / 名称、结果状态、获取时间与导出时间。

先排列页面中的项目自定义指标，再排列五项系统指标。每项指标包含：

- 指标值。
- 指标状态：有值、缺失指标、未录入结果，或不适用（其他项目）。
- 是否最佳：有值时输出“是 / 否”，无值时保持空白；并列最佳全部为“是”。

自定义指标列头包含项目 ID、项目名、指标名称、键、单位和优劣方向，跨项目同名 / 同键指标不合并。

选择基准时，另有基准 ID、基准编号、是否基准，以及每项指标的差值、差值状态和无法比较原因。“绝对差值”指当前实验减基准的带正负数值差，保留接口原始值，不计算百分比，也不取 `Math.abs`。未选择基准时不增加这些列。

缺失数值输出空单元格，合法 0 输出 `0`；数值使用 JavaScript 已取得的接口数值精度，不复用页面的缩略格式。格式为 UTF-8 BOM、逗号分隔、CRLF 行尾，文本字段加引号，内部引号和换行正确转义。公式形式的文本加单引号前缀，数值型负差值继续作为数值输出。

CSV 本身没有 Excel 单元格类型与样式。对于纯数字实验编号、前导零或特别高精度的数值，表格软件可能自行转换；需要保留这些文本时请使用其“从文本 / CSV 导入”功能指定列类型。该文件用于结果分析，不是批量新增实验所用的 JSON 导入格式。

## PNG 内容与排版

- 综合指标图、Loss 图、自定义指标图分别导出，图中继续展示原始数值，基准差值由 CSV 提供。
- 使用与页面相同的数据和图表选项生成独立画布；综合指标图保留当前图例开关。
- 图片包含标题、优劣方向、单位 / 自定义指标项目归属、完整换行的实验编号、最佳标记及获取 / 导出时间。
- 白色背景，2 倍像素倍率。最小逻辑宽度 1000，随实验数加宽；独立导出布局避免窄页面或横向滚动造成截图裁切。
- 为保证清晰度和控制临时画布资源，逻辑宽度最多 8192、最终像素数量最多 3200 万；超出时明确提示减少实验数或改用 CSV，不静默截掉实验或指标。标题、说明过长超出总尺寸限制也会提示。
- 导出结束或失败时释放独立 ECharts 实例、临时画布宿主和下载链接，页面现有图表保持可用。
