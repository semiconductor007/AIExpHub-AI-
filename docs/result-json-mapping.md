# 复杂结果 JSON 的指标识别与映射

2026-10-13 经用户反馈和授权完成独立改进。作用于单个实验的“录入结果 / 编辑结果”弹窗，支持粘贴及选择文件；不改变批量实验文档格式、后端 API 或数据库结构。此为 10 月 13 日的改进记录；2026-10-24 已另行完成配置复制和项目级映射模板，新增持久化与 API 见 [录入效率改进](entry-efficiency.md)。

## 使用方法

1. 打开当前实验的结果弹窗，粘贴 JSON 或选择 UTF-8 `.json` 文件。
2. 平铺且仅包含项目指标键的 JSON 继续自动填入。复杂对象 / 记录数组显示路径映射预览，唯一同名候选预选，但应用前不会改变表单。
3. 同一指标出现多个路径时，明确选择实际评测路径，或选择“不映射”。不会自动取训练值、最新 epoch、最大值或数组最后一项。
4. 字段名称不同，可在来源下拉框搜索、选择其他字段，例如把 test_acc 映射到 accuracy；只按准确的指标键生成候选，不推断别名或单位换算。
5. 展开“未映射 / 将忽略的字段”，核对是否有遗漏的指标或命名差异。点击“应用映射并确认忽略字段”，再核对 / 手动修正下方数值，最后保存结果。

例如：

```json
{
  "metadata": {"model": "ResNet18", "seed": 42},
  "training": {"accuracy": 0.99, "loss": 0.05},
  "evaluation": {"accuracy": 0.91, "loss": 0.2},
  "timing": {"test_latency_ms": 12},
  "logs": ["训练完成", "评测完成"]
}
```

选择 `$.evaluation.accuracy`、`$.evaluation.loss`；如项目已定义 latency_ms（ms），将 `$.timing.test_latency_ms` 映射到该指标。training、metadata 和 logs 的未选值在忽略预览中列明，不写入 Result。需要自行核对来源评测阶段、数值含义和单位。

## 表单语义与校验

| 情况 | 已实现行为 |
| --- | --- |
| 平铺指标对象，如 `{"accuracy":0.91,"loss":0.2}` | 合法时自动填入，未提供指标清空，保持旧行为 |
| 含无关字段、嵌套对象或数组的复杂 JSON | 先确认映射；只修改所选指标，未映射指标保留当前表单输入 |
| 所选值为 null | 清空该指标；映射整体至少需要一项有效数值 |
| 同名指标多次出现 | 必须选路径或明确不映射，不能在未处理歧义时应用 |
| 未找到同名指标 | 允许手动映射其他字段；没有有效数值时明确提示，不应用空结果 |
| 数字为 0 | 正常识别、填入和保存，不当作缺失 |
| 所选字符串数字、bool、数组、对象或非有限数值 | 明确报错，阻止应用与保存，不强制转换 |
| 所选指标越界 | 按当前项目定义拒绝，原输入保持不变 |
| JSON 语法非法或根为标量 / null | 明确报错，原输入不覆盖；修正或清空后继续 |
| 编辑 JSON 或更换路径 | 旧确认失效，重新应用后才能保存 |
| 应用后手动修改数值 | 保存采用最终表单值，不重解析 JSON 覆盖手动修正 |
| 清空 JSON | 保留已填表单值，恢复手动录入 |
| 关闭后重开弹窗 | 重置 JSON 与映射，加载当前实验最新结果 |

识别前不会发送整个原文件到后端。保存仍走原 Result API，提交五项系统指标及项目 custom_metrics，按最终完整表单更新；无关元数据、日志和原路径不存入数据库。API 继续执行严格类型、范围、项目归属和至少一项非空校验。

用户可以明确“不映射”某个不适合本次录入的源字段；不允许已选的非法值混入合法值。未选的无关数值即使溢出为非有限数值，也只列入忽略预览；一旦映射到指标就被拒绝。非标准 JSON 中的 NaN / Infinity 字面量仍为语法错误。

## 限制与实现

- 单结果文件与粘贴内容最多 1 MiB；节点预算 100,000，最多 20,000 个候选 / 标量字段，嵌套深度最多 100。超限明确拒绝并建议选择结果子对象，不截断扫描后伪装识别完整。
- 迭代遍历对象与数组；可读路径使用 `$...`，内部用转义后的 JSON Pointer 区分 `/`、`~` 和特殊键名，避免同名 / 特殊路径碰撞；不执行文件中的表达式。
- 映射下拉框使用现有 Element Plus 虚拟列表，支持搜索全部已扫描字段。忽略字段只展示前 20 项及总数，长文本截短显示，不向页面一次输出大量日志。
- 指标对象如 `{"accuracy":{"value":0.8}}` 按复杂结构处理，需要明确选择 value 子字段。
- 结果弹窗加宽并限制正文高度，正文内部滚动，保留标题、取消与保存区域。
- 不保存跨实验 / 跨项目映射模板，不自动计算指标，不自动换算单位或新增项目指标；批量实验入口继续使用原标准文档与严格校验，日志不能替代项目 / 批次 / 编号等业务字段。
