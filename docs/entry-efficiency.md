## E2：项目级 JSON 映射模板（已完成）

### 使用流程

1. 在实验结果弹窗粘贴或上传 JSON，核对指标路径，点击“应用映射并确认忽略字段”。
2. 点击“另存为映射模板”，输入名称。名称 trim 后必填，最多 100 个字符，在同一项目内区分大小写且不能重复。
3. 后续录入时选择“项目映射模板”，粘贴或上传同结构的新 JSON。模板可以在当前项目所有批次中复用；每次重新打开结果弹窗由用户自行选择，不自动套用上次模板。
4. 页面仅展示新文件中的实际候选数值；点击“应用映射”后才改变指标表单。核对或手动修正，再保存实验结果。

“重命名模板”只改名称。“更新模板映射”需要当前映射已应用，确认后替换模板；临时调整来源不会自动修改已保存模板。“删除模板”需确认，不影响已有实验和结果。刷新模板时重新读取定义并要求核对；加载失败时可以继续手动录入。

### 映射与异常规则

- 模板只保存指标身份和 JSON Pointer 对象路径，不保存指标数值、原 JSON、模型配置或日志；无关字段继续在本地预览并忽略。每个模板至少一个映射，同一指标只出现一次，最多 500 项。
- 系统指标按固定键识别，自定义指标按定义 ID 识别。名称、键或规则变化后，使用当前定义与当前范围校验。自定义指标被删除时，数据库将模板中该指标 ID 设为 null、保留失效标记；即使新指标同名或 SQLite 复用了 ID，也不会重新绑定。
- 路径不存在、值不是有限数值 / null 或超出当前范围时，不能应用。用户可重新选来源或明确“不映射”。失效指标必须明确“确认忽略已失效指标”或重新映射到当前指标，再应用；主动更新模板才能保存修正。
- 模板模式未映射项保留表单当前输入；映射到 null 清空该项。至少映射一个有效数值才能应用，不用默认值补齐缺失。应用后手动修正保存时不重新解析 JSON。
- 第一版模板只复用对象路径。含数组下标的映射可以用于当次手动录入，但不能存成模板；若文件结构从对象变成数组，即使 Pointer 文本相同，也会阻止直接套用。数字形式的对象属性名仍允许，不被误判为数组。API 保存的是对象路径约定，实际是否穿过数组在浏览器解析文件时检查，不上传原文件。
- 路径遵循 JSON Pointer 的 `/` 分段、`~0` / `~1` 转义，最多 100 层、4096 个字符。文件保留既有 1 MiB、节点数及字段数限制。不推断最新轮次、最佳值、单位转换或指标别名。
- 不选择模板时，原平铺 JSON 自动填入和复杂 JSON 手动映射保留。批量实验导入继续使用原项目模板格式，不套用此处的单结果映射。

### 持久化与 API

新增 `result_mapping_templates`（项目、名称）和 `result_mapping_entries`（模板、指标身份、路径）两张表。Project 删除时模板及映射一并删除；删除模板不会删除指标定义。自定义指标删除时映射失效，沿用原“已被结果使用的指标不能删除”规则。

启动时检查既有库：若已存在项目表但缺少新表，先生成 `backend/data/aiexphub.pre-mapping-templates-<UTC时间>.db` 备份，再通过现有 `create_all` 添加新表；不重写原五张表和记录。重复启动不重复备份，新库直接建表。备份和运行库均已被 Git 忽略；本次另外保留了实施前 `pre-entry-efficiency` 备份。备份失败会中止初始化。恢复备份需要先停止后端并另存当前库，恢复后再次启动会重新补建缺少的表。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/projects/{project_id}/result-mapping-templates` | 列出当前项目模板及映射 |
| POST | 同上 | 新建，成功 201 |
| PUT | `/projects/{project_id}/result-mapping-templates/{template_id}` | 完整替换名称及映射 |
| PATCH | 同上 | 只重命名，传入 name |
| DELETE | 同上 | 删除模板，成功 204 |

POST / PUT 请求示例：

```json
{
  "name": "评估脚本输出",
  "mappings": [
    {"metric_key": "accuracy", "metric_id": null, "builtin": true, "pointer": "/evaluation/acc"}
  ]
}
```

自定义指标传入真实 `metric_id`、当前 `metric_key` 及 `builtin: false`。返回包含 `id`、`project_id`、`name` 和 `mappings`；失效自定义映射保留 `builtin: false, metric_id: null`。不存在或跨项目模板返回 404；非法名称、路径和指标身份返回 422；同项目重名返回 409。失败的替换事务回滚，不丢失旧映射。请求不接受原文件或结果值等额外字段。
