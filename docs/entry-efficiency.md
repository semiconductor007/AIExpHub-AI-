# 录入效率改进

实施日期：2026-10-24。按用户审核方案分为 E1 配置复制和 E2 项目级映射模板。

## E1：复制实验配置（已完成）

实验管理列表点击“复制配置”，打开预填的新建表单。模型、完整嵌套参数和备注可修改；编号留空，仍按 trim + uppercase 后全局唯一校验。默认原批次，可选择同项目其他批次。保存成功后切换到目标批次并展示新实验。

只在“保存实验”时调用既有创建接口。源实验不变，新实验使用新 ID、服务端创建时间，没有实验结果；取消和校验失败不写入数据。复制参数通过 JSON 文本形成独立编辑内容，不共享源参数引用。未新增复制 API 或数据库字段。

验收：前端 26 项测试及构建通过；真实页面验证空编号、重复编号拒绝、修改嵌套参数后跨批次创建，新实验无结果。后端 GET 核对源配置及结果不变。原手动新建、编辑、导入和删除继续使用原流程。

## E2：项目级 JSON 映射模板

待实现：保存、使用、重命名、更新和删除项目级命名映射。模板保存指标身份和对象路径，不保存结果数值或原 JSON。含数组下标路径不允许保存为复用模板。使用时预览并明确应用，路径或指标失效不得静默替换。
