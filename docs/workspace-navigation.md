## 使用路径

首次使用可从首页了解项目 / 批次 / 实验关系，并通过“新建实验”直接开始录入。无项目或无批次时按需创建后继续，取消或刷新不重复弹窗；详见 [首页介绍与首次使用引导](home-guide.md)。

1. 在“项目管理”创建或编辑项目，点击“进入项目”。
2. “项目工作区”默认列出项目下全部实验；批次是可选筛选条件。“管理批次”和“管理指标”按需打开，指标仍由项目共享。
3. 新建实验必须选择所属批次；已有批次筛选时默认带入。批量导入在原弹窗内选择目标批次，切换目标会撤销旧预览，必须重新校验后确认。
4. 列表展示编号、批次、模型、创建时间与操作，完整参数及备注收进详情。点击“查看详情”在抽屉中查看模型、批次、备注、完整参数和当前结果。可编辑配置、复制配置或录入 / 编辑结果。关闭抽屉保留列表筛选和勾选。
5. 在列表勾选至少两个实验后点击“比较所选实验”。批次筛选不清空其他批次的勾选，切换项目会清空。
6. 比较页根据地址中的实验 ID 获取最新记录并执行普通比较。需要更多实验时打开“添加实验”，支持跨项目、跨批次加入。
7. 比较页的“指标表格”“可视化”“AI 总结”共用已选实验与基准。表格按指标行、实验列展示，支持指标筛选和实验分组，基准固定；详见 [指标对照表](comparison-table.md)。完整比较可导出 CSV，各图导出 PNG；AI 仅在预览后明确点击“发送并生成”时调用。

## 链接与状态

- 旧 `/projects`、`/experiments`、`/compare` 路由继续保留；工作区仍支持 `projectId` 和可选 `batchId`。
- 比较地址示例：`/compare?ids=4,5,7&baseline=4`。只记录 ID，不将参数、结果或密钥放进地址。刷新恢复选择并读取当前数据，不恢复旧结果快照。
- 比较 ID 必须为安全的正整数，以 ID 去重并保留选择顺序。无效链接显示错误；已删除实验显示失效项，可移除。网络加载失败可重新加载所选实验。
- 没有 Result 的实验仍可进入数值比较，缺失指标不补 0；AI 继续遵循同项目、有效结果及共同指标等原有限制。
- 标签切换保留已生成 AI 总结和图表实例；图表可见时更新数据与尺寸。相关数据变化后，比较刷新、旧 AI 总结标记过期，均不自动重新生成 AI 内容。
- 使用说明收进“比较与导出说明”帮助入口。删除 AI 区域原常驻 DeepSeek 操作提示；必要的失败、过期和发送确认信息仍显示。

## 最小后端扩展

新增只读 `GET /projects/{project_id}/experiments`：返回项目下所有批次的实验，按实验 ID 升序；结构沿用 ExperimentRead，不逐条附带 Result。存在但没有实验的项目返回 `[]`，不存在的项目返回 404 `Project not found`。批次内列表及单条查询继续保留，比较链接恢复复用单条实验和批次查询。
