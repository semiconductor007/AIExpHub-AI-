# 结果 JSON 快速录入

2026-10-13 后续增量已支持 [选择 JSON 文件与批量实验导入](json-file-import.md)，下文保留初次粘贴入口的历史记录；原手动修正与完整更新语义保留。

之后已支持 [复杂结果 JSON 的指标识别与映射](result-json-mapping.md)，无关字段可预览忽略，同名候选需选择，复杂模式未映射项保留当前输入；平铺模式沿用自动填入和省略项清空规则。

2026-10-12，经用户确认的独立增量改进。用于减少课程示例数据逐项填写的操作，不代表真实模型实验指标已由平台计算，也不替代阶段 6B 的人工窗口、讲解与视频检查。

## 使用

进入实验管理，选择实验并点击“录入结果”或“编辑结果”，在“JSON 快速录入”中粘贴：

```json
{
  "accuracy": 0.86,
  "precision": 0.84,
  "recall": 0.83,
  "f1": 0.835,
  "loss": 0.28
}
```

粘贴合法 JSON 后自动填入下方五项数值，无需再点填入按钮。可继续手动修改，再点击“保存结果”；保存使用修正后的表单值，不重新用 JSON 覆盖修正。若需要重新应用原 JSON，可点击“重新填入指标”。填入本身不发请求、不保存数据；取消后原结果保持不变。非法 JSON 会就地提示并阻止保存；修改为合法 JSON 或清空 JSON 后可继续录入。

## 规则与范围

- 输入必须是合法 JSON object，支持五项系统指标和所属项目已配置的自定义指标键；未知键明确报错，避免拼写错误被静默忽略。
- 至少一项非 null；值只允许有限数值或 null，拒绝字符串和布尔值。
- accuracy / precision / recall / f1 范围 [0,1]，loss >= 0；自定义项遵循各自配置的上下限。真实 0 合法。
- 未提供和 null 的指标都清空对应输入；编辑时如需保留其他指标，请一并提供，或填入后在表单中补齐再保存。
- 全部解析和验证成功后才一次替换表单；失败不覆盖已填内容。重新打开弹窗清空 JSON 草稿与错误，恢复当前保存的指标。
- 复用范围校验和 Result POST / PUT。最初 JSON 入口只改前端；后续经授权实现了项目共享指标 API 与数据库扩展，详见 [共享指标说明](project-metrics-proposal.md)。仅支持当前单次实验的结果填入，未增加文件批量导入、批量实验或自动指标计算。

## 自动填入修正

用户反馈直接粘贴后点击保存仍报至少需要一个指标：旧版本需要额外点击“填入指标”。已改为监听 JSON 内容变化、同步完整校验并自动填入，保留手动修正；提交时不再重新解析并覆盖修正值，JSON 当前错误时阻止提交。

本次独立临时实验的真实页面回归：直接粘贴完整五项 JSON 后直接保存成功；八类非法 JSON 自动提示并保持原输入，点击保存时弹窗保留；部分 JSON 中的 0 / null 正确填入，手动把 accuracy 改为 0.91 后保存，GET 返回 0.91、loss=0、其余为 null。Console warn / error 日志为空。临时数据经正常 API 删除，原四表行数据摘要不变，计数恢复 2 / 2 / 3 / 2。

修正后 TypeScript / build 成功，Vite 输出 857ms，JS 1,610.88 kB / gzip 527.39 kB，保留大包警告；没有后端或依赖修改。本次没有重新执行 pytest，上节 102 passed 是此前增量验证的实际记录。

## 项目共享指标联动

2026-10-13 完成共享指标扩展，输入采用平铺键值，例如先在项目中定义 latency_ms 后可粘贴 `{"latency_ms":23.5}`。表单读取项目定义并自动校验、填入，保存时转换为 API 的 custom_metrics 对象。支持只填写自定义指标，至少一项有效；完整 PUT 的省略项清空规则保持。最新整体验证为 139 passed、1 warning（16.60s），TypeScript / build 成功，原数据保留。此前各节的 102 个测试及前端单独修正记录为当时的历史证据。
